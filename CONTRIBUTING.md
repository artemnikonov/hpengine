# Contributing to HPEngine

Thank you for helping.

- **People:** [docs/contributing.md](docs/contributing.md) covers building, the checks you can run, and the rules a
  pull request is reviewed against (behaviour exactly as in the original game, marked improvements, one owner of game
  state, sources and origin tags).
- **AI coding agents:** [AGENTS.md](AGENTS.md) states the same rules as a do/don't checklist.

To report a bug, open an issue: the template asks for the edition, platform, map, what happened and the run log. If you
can compare with the original game, say how it behaves there.
